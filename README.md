# Grey Mushaf

A Quran revision app. Pages show greyed text, and long-pressing a word you forget turns it black for
good. Over time each page shows only your weak spots, so a quick review of many pages focuses on
exactly those words.

- `make_grey_mushaf.py` builds a greyed PDF from the KFGQPC 1441 Madinah (Hafs) Illustrator pages.
- `app/` (coming) is the Flutter app for Android phones and Boox e-ink tablets. It works offline, with
  optional sync.
- `docs/rulings.md` holds the product decisions.

The source mushaf files are not included in this repo. Get them from KFGQPC.
