# Web build plan (R56, R85–R88)

Base 3c6ee6d. Sensitive: PocketBase auth (new session/gate routes), Caddy access to gated assets.

## Pieces

1. **Web scaffolding.** `flutter create --platforms=web .` in `app/` (index.html, manifest, icons).
   Build: `flutter build web --release`; output `app/build/web/` (assets/mushaf + assets/index inside).
2. **Local store on web.** `reveal_store.dart:317` opens sqflite. On web use
   `sqflite_common_ffi_web` (`databaseFactoryFfiWeb`, IndexedDB-backed); run its setup to place
   `sqlite3.wasm` + `sqflite_sw.js` in `app/web/` at build time. Same schema, same sync engine (R88).
3. **`dart:io` in `sync.dart:3,85`.** Offline is detected with `on SocketException`; on web the http
   client throws `http.ClientException`. Treat `ClientException` as Offline on every platform.
4. **Sign-in first on web (R88).** `main.dart` loads `assets/mushaf/pages.json` and fonts before the
   reader. On web, when `sync.signedIn` is false, show the sign-in screen (`account_screen.dart`)
   first; after sign-in (or when already signed in) call the session route, then load the mushaf.
   A 401 on an asset after the session lapses shows the sign-in screen again.
5. **Gate (R87).** PocketBase hooks in `server/pb_hooks/web_session.pb.js`:
   - `POST /api/mushaf/session` requires the `Authorization` token (`$apis.requireAuth("users")`),
     responds 204 with `Set-Cookie: mushaf_session=<token>; Path=/; HttpOnly; Secure;
     SameSite=Strict; Max-Age=<token remaining>`.
   - `DELETE /api/mushaf/session` clears the cookie (sign-out).
   - `GET /api/mushaf/gate` reads the cookie, `$app.findAuthRecordByToken(token, "auth")`, requires
     collection `users` and verified, returns 204 or 401. Never echoes the token.
   The cookie is never accepted by any data route: those keep using the Authorization header, so
   the cookie adds no CSRF surface.
6. **Caddy block** (`~/Documents/vps-infra/caddy/Caddyfile:125`), keep headers and the superusers
   404:
   - `handle /api/*` and `handle /_/*` → `reverse_proxy 127.0.0.1:8093` (as today).
   - `@gated path /assets/mushaf/* /assets/index/*` → `forward_auth 127.0.0.1:8093 { uri
     /api/mushaf/gate }` then `file_server` from `/srv/mushaf.ahmadjz.tech/web`.
   - everything else → `root /srv/mushaf.ahmadjz.tech/web`, `try_files {path} /index.html`,
     `file_server`; `Cache-Control: no-cache` on index.html, flutter_bootstrap.js, and the
     `main.dart.js` hash-less files.
   - Add `Content-Security-Policy` only if CanvasKit from gstatic works with it; else build with
     `--no-web-resources-cdn` so CanvasKit is served locally.
   Deploy: back up Caddyfile, `caddy validate`, reload; recheck the other sites (ahmadjz, office,
   tariq, sohba, visa) return what they did before. rsync `build/web/` to
   `/srv/mushaf.ahmadjz.tech/web/`; copy the hook into `/srv/mushaf.ahmadjz.tech/pb_hooks/`.
7. **Mouse and keys (R56).** Holding the mouse button is a long-press (default recognizer accepts
   mouse; check). Wheel down / ArrowLeft = next page, wheel up / ArrowRight = previous (RTL, like
   the left arrow = next in R45); one turn per wheel notch burst (debounce ~250 ms); a spread in
   landscape-wide windows. Implemented with a `Listener(onPointerSignal)` and `Focus(onKeyEvent)`
   around the reader, reusing the arrow-button page-turn path (instant, R74).
8. **Platform channels.** `isEInkDevice` already catches `MissingPluginException`; check every
   `_platform.invokeMethod` in `main.dart` does too.

## Proof

- Widget tests: wheel and arrow keys turn pages (next/previous, spread); signed-out web shell shows
  sign-in (via an injectable `isWeb` flag); ClientException → Offline.
- Server: curl `assets/mushaf/50.json` and a `.ttf` signed out → 401; with cookie from the session
  route → 200; expired/garbage cookie → 401; a superuser token cookie → 401; DELETE clears.
- Live in Chrome (chrome-devtools): sign in as a test account, page 1, 2, 50 render; long-press with
  mouse reveals; wheel and arrow keys turn; reveal syncs to an emulator signed into the same account.
- Other sites unchanged after Caddy reload.
